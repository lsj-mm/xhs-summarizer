Python 调用第三方 API（以 GitHub 为例）

先查文档确认接口地址、参数、鉴权方式和返回结构，再用 requests 发请求； 用 raise_for_status() 检查 HTTP 状态，最后按 JSON 字段解析。

import requests

resp = requests.get(
    "https://api.github.com/search/repositories",
    params={"q": "keyword", "sort": "stars", "per_page": 5},
    headers={"Accept": "application/vnd.github+json"},
    timeout=15,
)
resp.raise_for_status()
for repo in resp.json()["items"]:
    print(repo["full_name"], repo["stargazers_count"])

MySQL 关键字查询

小表用 LIKE 快速实现；大表用 FULLTEXT（中文加 ngram 解析器）， 并用 EXPLAIN 确认是否走索引。

-- 1) 包含匹配（注意前置 % 会让普通索引失效）
SELECT id, title
FROM articles
WHERE title LIKE CONCAT('%', ?, '%')
   OR body  LIKE CONCAT('%', ?, '%')
LIMIT 50;

-- 2) 全文索引 + 相关性排序
ALTER TABLE articles
  ADD FULLTEXT INDEX ft_articles (title, body);

SELECT id, title,
       MATCH(title, body) AGAINST (? IN NATURAL LANGUAGE MODE) AS score
FROM articles
WHERE MATCH(title, body) AGAINST (? IN NATURAL LANGUAGE MODE)
ORDER BY score DESC
LIMIT 50;

-- 3) 看执行计划
EXPLAIN ANALYZE SELECT id, title FROM articles
WHERE title LIKE '%mysql%' LIMIT 50;

中文全文检索用 WITH PARSER ngram；参数一律用占位符，不要拼接 SQL。

前端如何接查询接口

输入用防抖，请求用 AbortController 取消上一次；返回后先检查 res.ok，再渲染并处理空结果/错误。

let timer;
let controller;

function onInput(q) {
  clearTimeout(timer);
  timer = setTimeout(() => search(q), 200);
}

async function search(q) {
  if (controller) controller.abort();
  controller = new AbortController();
  const res = await fetch(
    "/api/search?q=" + encodeURIComponent(q),
    { signal: controller.signal }
  );
  if (!res.ok) throw new Error("HTTP " + res.status);
  const data = await res.json();
  render(data.items);
}
C++ / Java / Go 的检索思路

C++：std::string::find / std::regex，大文本先建倒排或前缀树。

Java：String.contains / Pattern，服务端可用 Lucene/Elasticsearch。

Go：strings.Contains / regexp，并发检索用 goroutine + channel 汇总。

// Go：并发检索多个分片，合并命中结果
func search(shards []string, kw string) []string {
    ch := make(chan []string, len(shards))
    for _, s := range shards {
        go func(s string) {
            var hits []string
            if strings.Contains(s, kw) {
                hits = append(hits, s)
            }
            ch <- hits
        }(s)
    }
    var out []string
    for range shards {
        out = append(out, <-ch...)
    }
    return out
}
